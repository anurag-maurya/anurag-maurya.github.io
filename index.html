  • Self-Hosted Apache Superset & Analytics Consolidation: Migrated customer analytics end-to-end from paid AWS QuickSight ($3/user) to self-hosted Apache Superset across 40+ multi-user customers, removing manual per-user provisioning and consolidating scheduled reports previously run on Redash.
  • Hybrid AI Invoice Validation Engine: Built a Gemini LLM + deterministic Python validation pipeline to parse unstructured transporter PDFs, cross-check freight charges against active contracts, flag SLA deviations, and route low-confidence cases to a human-in-the-loop review queue.
  • High-Scale Microservices Ecosystem: Scale and maintain a 15+ service distributed logistics ecosystem powered by Kafka (event-driven communication) and Redis (caching/locking), processing lakhs of transactions daily.
